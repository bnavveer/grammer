Small edits, one shortcut away.

Select text on a webpage or inside an editor. Press a shortcut, choose an action from Grammer's toolbar, or right-click the selection.

Your two actions

Fix grammar Alt ⇧ G sends only your selection to Gemini. Review the result, make any changes in the preview, then replace the selection or copy it.

Remove formatting Alt ⇧ P prepares plain text locally. Replacing it strips inline fonts, colors, bold, highlighting, and links. The editor's own default styles still apply. Literal Markdown symbols stay as written.

Both actions return plain text. A read-only selection offers copying. Close the preview or press Escape while it is focused to cancel a pending request.

Change your hotkeys

Click the button below to open Chrome's shortcut editor. Find Grammer, click the pencil next to either action, and press the keys you want. Chrome saves them automatically. Return to Grammer to see the new bindings.

You can also open this editor from Settings or the popup. Chrome keeps your assignments when the extension reloads or you reset Grammer's settings. OS shortcuts and other extensions can take priority.

Connect Gemini

Get a Gemini API key from Google AI Studio. Paste it in Settings, then click Save & connect and allow Chrome to contact Gemini.

Grammer uses Gemini 3.5 Flash-Lite with minimal thinking for quick corrections. Test connection sends one example sentence; Google's API quotas and billing apply. No model or endpoint configuration is needed.

Keys are session-only unless you choose to remember them. A session-only key clears when Chrome restarts or the extension reloads, updates, or is disabled. Remembered keys are stored locally without encryption and never sync.

If something doesn't work

  • Nothing happens on a shortcut: check its assignment in Chrome's shortcut editor. Chrome must be focused.
  • A ! badge appears: Chrome blocked the action. Open the toolbar and retry to see the explanation.
  • The editor changed: copy the preview, or select your current text and run the action again. Grammer blocks replacement to protect newer edits.
  • Replacement isn't supported: use Copy plain text and paste through the editor. Google Docs' canvas, custom document models, closed shadow roots, and cross-origin frames aren't guaranteed.
  • A page is restricted: Chrome's internal pages, the Web Store, and its PDF viewer block extension access.
  • A Gemini error appears: check your key, project quota, model access, and connection. Requests time out after 25 seconds; selections can contain up to 16,000 characters.

Use your editor's Undo to revert a replacement. Rich-text cleanup can require more than one Undo step. Gemini can make mistakes or change meaning, so review its output before applying it.

Privacy and reporting

Grammer has no analytics, text history, or developer-operated backend. Grammar requests go straight to Google. Read the privacy policy for details.

Report ordinary bugs in the source repository using public sample text. For vulnerabilities, use private vulnerability reporting if enabled, or ask the maintainer for a private channel. Never post API keys or private documents.
